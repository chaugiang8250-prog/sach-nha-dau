# Website bán hàng tích hợp quản trị tồn kho cho Sách Nhà Đậu

## 1. Giới thiệu
Dự án xây dựng website bán sách ngoại đã qua sử dụng, tích hợp chức năng quản trị tồn kho cho Sách Nhà Đậu.

## 2. Mục tiêu
- Hiển thị danh mục và thông tin sách.
- Hỗ trợ khách hàng đặt hàng và tra cứu đơn hàng.
- Quản lý sách, lô nhập và tình trạng tồn kho.
- Hỗ trợ chủ shop quản lý đơn hàng và tiền cọc.

## 3. Tài liệu thiết kế hệ thống
Các tài liệu thiết kế được lưu trong thư mục `docs/`:
- ERD Diagram
- ERD Checklist
- Relational Schema
- DFD–ERD Consistency Matrix
- System Architecture

Wireframe sẽ được bổ sung sau.

## 4. Cấu trúc repository
- `docs/`: Tài liệu thiết kế hệ thống
- `backend/`: Mã nguồn backend
- `database/`: Tài liệu database, migrations và sample data

## 5. Trạng thái dự án
Hiện tại, dự án đang trong giai đoạn thiết kế hệ thống và chuẩn bị môi trường phát triển.
